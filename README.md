# 인구 불균형 체험 놀이

초등학교 5학년 사회 수업용 1인 체험형 웹 게임입니다.

## 실행 방법

브라우저에서 `index.html`을 열면 바로 실행됩니다.

로컬 서버로 실행하려면 아래 명령을 사용합니다.

```powershell
node server.js
```

접속 주소는 `http://127.0.0.1:4173`입니다.

## 게임 흐름

1. 학생이 `게임 시작`을 누릅니다.
2. 라운드 상황을 읽고 핵심 조건 카드 2개를 고릅니다.
3. `수도권` 또는 `지방` 선택지를 터치합니다.
4. 생활 주사위를 굴려 취업 판정과 추가 생활 이벤트를 확인합니다.
5. 선택에 따라 취업, 월세, 교통비, 환경비가 계산됩니다.
6. 조건 카드를 잘 고르면 분석 보너스 코인을 받습니다.
7. 9라운드가 끝나면 선택 기록과 정리 질문이 나옵니다.

## 포함된 내용

- 인생게임식 9라운드 진행
- 현재 거주지, 위기, 기회에 따라 달라지는 33개 분기 시나리오
- 조건 카드 퍼즐
- 굴러가는 주사위 액션
- Web Audio 기반 효과음
- 학생 직접 터치 선택
- 지역별 수입과 지출 자동 계산
- 지방 취업 주사위 판정
- 코인 변화와 선택 기록
- 마무리 토의 질문
